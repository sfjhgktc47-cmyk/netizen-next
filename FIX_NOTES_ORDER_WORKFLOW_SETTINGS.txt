Исправления заявок / статусов

1. Добавлена страница: /nz-console/orders/settings
2. Статусы теперь можно добавлять, скрывать, удалять, сортировать и окрашивать отдельно для:
   - курьерской доставки;
   - самовывоза / ПВЗ.
3. Можно выбрать стартовый статус для каждого способа получения.
4. При смене способа получения статус автоматически переключается на стартовый статус нового способа.
5. В карточке заявки способы получения и статусы выведены кнопками.
6. В карточке заявки можно менять адрес доставки / пункт выдачи.
7. Фильтры и вкладки на странице заявок строятся из настроек.
8. Новые заявки получают стартовый статус из настроек.
9. Prisma-поле Order.status переведено с enum на String. Добавлена миграция:
   prisma/migrations/20260611170000_order_status_settings/migration.sql
10. В npm start добавлен prisma migrate deploy, чтобы миграция применялась при запуске Railway.
