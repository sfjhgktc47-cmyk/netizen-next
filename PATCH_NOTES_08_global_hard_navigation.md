# Patch 08 — Global hard navigation

Что исправляет:

- Отключает клиентскую навигацию Next.js для внутренних ссылок по всему сайту.
- Все обычные внутренние ссылки теперь открываются через полноценный переход страницы.
- Это должно убрать баг, когда URL меняется с первого клика, а контент реально обновляется только со второго клика.

Что не трогает:

- Внешние ссылки.
- `mailto:`, `tel:`, `sms:`.
- Ссылки с `target="_blank"`.
- Скачивание файлов через `download`.
- Якоря на той же странице.
- Формы, кнопки, поиск и другие действия без обычной ссылки.

- `src/components/hard-link-navigation.tsx`
- `src/app/layout.tsx`
