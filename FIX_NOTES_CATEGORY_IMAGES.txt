Исправление: категории на главной странице

Что изменено:
1. src/lib/public-categories-db.ts
   - категории явно выбираются из Prisma через select;
   - image/description/name/slug очищаются от пробелов;
   - публичная модель категории больше не теряет image и description.

2. src/app/api/home/route.ts
   - отключен кеш: dynamic force-dynamic, revalidate 0, fetchCache force-no-store;
   - добавлены no-store headers;
   - categories возвращаются с нормализованными image и description;
   - при ошибке API возвращает status 500, чтобы проблема была видна.

3. src/app/page.tsx
   - отключен кеш для главной страницы;
   - initialData.categories нормализует image и description перед передачей в HomeClient.

После загрузки архива на сервер:
npm install
npx prisma generate
npm run build

Если после этого картинки всё равно пустые в /api/home, значит сайт подключен не к той базе DATABASE_URL или в активных категориях image пустой.
