# Patch 18 — Admin product form tabs

Изменения:

- Создание карточки и редактирование карточки разделены на 3 вкладки:
  - Основная информация
  - Фото
  - Описание и характеристики
- Кнопка сохранения закреплена снизу экрана.
- Фото вынесены отдельно:
  - фото карточки для главной и каталога
  - галерея карточки
  - фото для блока «Новинки»
- Характеристики больше не одно большое поле. Теперь это строки:
  - название характеристики
  - значение
- Подсказки для характеристик и брендов берутся из уже созданных карточек и SKU.
- Характеристики сохраняются в старое поле `characteristics`, без новой миграции БД.
- `image` теперь используется как отдельное фото карточки, а `images` как галерея.
- API создания и редактирования карточки теперь сохраняет `characteristics`.
- Секция SKU на странице карточки перенесена внутрь вкладки «Основная информация».

Базу данных менять не нужно.
