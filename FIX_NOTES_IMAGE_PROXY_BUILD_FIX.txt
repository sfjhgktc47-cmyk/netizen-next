Build-fix для image-proxy.

Причина:
- В src/app/api/public-image/[...parts]/route.ts использовался RegExp flag /s.
- TypeScript target проекта ниже ES2018, поэтому сборка падала:
  "This regular expression flag is only available when targeting es2018 or later."

Что исправлено:
- parseDataImage переписан без regex-флага /s.
- Логика осталась та же: data:image/...;base64,... разбирается через indexOf/slice.
