Исправлена ошибка npm ETIMEDOUT при скачивании xlsx.

Причина:
package-lock.json содержал ссылки на внутренний OpenAI Artifactory:
packages.applied-caas-gateway1.internal.api.openai.org
Этот адрес недоступен при обычном деплое.

Исправления:
- все внутренние resolved URL заменены на https://registry.npmjs.org/;
- Nixpacks использует npm ci по lock-файлу;
- явно задан публичный npm Registry;
- добавлены повторные попытки и увеличенный сетевой тайм-аут;
- devDependencies устанавливаются для production build.
