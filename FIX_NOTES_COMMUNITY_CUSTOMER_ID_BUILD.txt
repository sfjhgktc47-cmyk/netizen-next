Исправлена блокирующая TypeScript-ошибка в голосовании за отзыв.

Причина:
- session.customerId внутри Prisma transaction определялся как string | undefined.

Исправление:
- После проверки авторизации customerId сохраняется в отдельную константу.
- Все операции голосования используют гарантированный string customerId.

Предупреждения ESLint из лога не блокируют сборку.
