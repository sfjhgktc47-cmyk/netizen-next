Фикс поверх sayt obnova.zip.

Что восстановлено:
1. Блок преимуществ на главной:
- убрана жёсткая сетка на 5 колонок;
- блок снова динамически растягивается по ширине;
- внутренние карточки без рамок;
- картинки преимуществ не зажимаются в круг;
- текст не режется line-clamp.

2. Публичный каталог:
- возвращён sortOrder у карточек товаров в публичные данные;
- сортировка товаров снова идёт по sortOrder;
- бренды в каталоге сортируются по минимальному sortOrder товаров внутри бренда.

3. Админка карточек товаров:
- вернулась колонка 'Порядок';
- можно менять sortOrder прямо из списка карточек;
- API обновления порядка меняет только sortOrder и не требует пересохранения всей карточки.

4. Админка позиций:
- добавлен фильтр по бренду;
- фильтр моделей показывает #sortOrder · модель · бренд;
- добавлены колонки 'Бренд' и 'Порядок';
- позиции сортируются по порядку материнской карточки, потом по бренду и дате.
