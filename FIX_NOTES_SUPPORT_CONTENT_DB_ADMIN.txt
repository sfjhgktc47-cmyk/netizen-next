Блок 'Сервис и поддержка Нетизен' связан с PostgreSQL.

Добавлено:
- SupportFeature для карточек преимуществ слева.
- SupportFaqItem для вопросов и ответов справа.
- Стартовая миграция переносит текущий контент.
- Публичный API /api/support-content.
- Админский API /api/admin/support-content.
- Админка /nz-console/support-content.
- Можно добавлять, редактировать, скрывать, сортировать и удалять элементы.
