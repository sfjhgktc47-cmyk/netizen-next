Исправление бага: при изменении порядка категорий/товаров пропадали описания и картинки.

Причина:
Компонент SortOrderInput отправлял PATCH на обычное сохранение сущности, но передавал только часть полей. API воспринимал отсутствующие поля как пустые строки и затирал image, description, seo и другие данные.

Что исправлено:
1. SortOrderInput теперь отправляет action: "set-sort-order".
2. API категорий src/app/api/admin/categories/[id]/route.ts при action "set-sort-order" обновляет только sortOrder.
3. API товаров src/app/api/admin/products/[id]/route.ts при action "set-sort-order" обновляет только sortOrder.
4. Дополнительно обычный PATCH категорий/товаров больше не затирает поля, которых нет в body. Если поле не отправили — оно остается как было в БД.

Замененные файлы:
- src/components/admin/sort-order-input.tsx
- src/app/api/admin/categories/[id]/route.ts
- src/app/api/admin/products/[id]/route.ts
