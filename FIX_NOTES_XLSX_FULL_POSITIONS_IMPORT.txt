Фикс: полный XLSX-импорт позиций

Что изменено:
- Шаблон /api/admin/positions/template теперь содержит полный набор колонок из формы позиции.
- Добавлен второй лист readme с пояснением по колонкам.
- Импорт поддерживает поля позиции/SKU:
  productId, productSlug, slug, sku, name, memory, color, colorHex, sim,
  price, oldPrice, stock, status, seoTitle, seoKeywords, seoDescription, images.
- Импорт поддерживает поля материнской карточки:
  model, brand, category, categorySlug, categorySortOrder, productSortOrder,
  productStatus, isNew, isPopular, productImage, promoImage,
  shortDescription, description.
- Если SKU уже существует, обновляются только заполненные ячейки.
- Если SKU новый, позиция создаётся. Если материнской карточки или категории нет — они создаются.
- Пустые ячейки не затирают старые данные.

Минимум для обновления цены/остатка:
sku, price, stock

Минимум для создания новой позиции:
sku, model, brand, category, price

Фото можно передавать одной или несколькими ссылками через точку с запятой, запятую, вертикальную черту или перенос строки.
