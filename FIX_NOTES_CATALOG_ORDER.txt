Исправление каталога: управление порядком брендов и товаров.

Что изменено:
1. В публичные данные товара добавлено поле sortOrder.
2. Каталог теперь сортирует бренды по минимальному sortOrder товаров внутри бренда.
   Пример: если у Samsung самый маленький sortOrder = 10, а у Apple = 20,
   блок Samsung будет выше Apple.
3. Товары внутри каждого бренда при сортировке "Популярные" идут по sortOrder.
4. В админке /nz-console/products добавлено быстрое поле "Порядок" для каждой карточки.
5. В создании и редактировании карточки товара добавлено поле "Порядок в каталоге".

Как пользоваться:
- Открой /nz-console/products.
- У товара поставь меньшее число, чтобы он был выше.
- Чтобы поднять бренд выше, поставь одному или нескольким товарам этого бренда меньшее число.

Пример:
Samsung S26 Ultra: 10
Apple iPhone 17 Pro Max: 20
Apple iPhone 17: 30
Apple iPhone 17 Pro: 40

В каталоге сначала будет Samsung, потом Apple.
Внутри Apple товары будут идти 20, 30, 40.

После заливки:
npm install
npx prisma generate
npm run build
