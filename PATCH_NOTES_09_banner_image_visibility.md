# Patch 09 — видимость фото основного баннера

Что исправляет:

1. Фото баннера на главной могло не обновляться/не отображаться из-за кеша `/api/public-image/...` и Next Image.
2. Теперь URL фото баннера получает версию по `updatedAt`, поэтому после сохранения баннера браузер берёт свежее изображение.
3. Для макета `Текст + фото` изображение баннера выводится в правой части hero-блока, а не как фон на весь блок.
4. Макет `Фото фоном` продолжает работать как фоновый вариант.

После деплоя, если баннер всё ещё пустой, пересохраните баннер в админке: `Редактор сайта → Библиотека/баннеры → Сохранить баннер`.
