Исправлено сохранение иконок нижней навигации.

Причина:
- настройки сохранялись уже с URL вида /api/public-image/setting/..., а не с исходной data:image.
- после повторного сохранения API не мог декодировать картинку и предпросмотр показывал битую иконку.

Что сделано:
- в БД теперь сохраняется исходная data:image;
- клиенту по-прежнему возвращается короткий /api/public-image/... URL;
- уже сломанные старые URL для navIcon* больше не ломают страницу: API отдаёт SVG fallback;
- publicImageUrl больше не оборачивает /api/public-image/... повторно;
- предпросмотр в админке не показывает битый img, а откатывается на обычный символ.
