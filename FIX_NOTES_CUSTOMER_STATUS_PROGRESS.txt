Добавлена система статусов клиентов.

Статусы:
- Новый клиент
- Постоянный клиент
- VIP

Раздел Клиенты:
- настраиваемая минимальная сумма заказа, который учитывается;
- количество завершённых заказов для постоянного клиента;
- количество заказов для VIP;
- сумма покупок для VIP;
- VIP присваивается по одному из условий: количество или сумма;
- учитываются только завершённые заявки.

Карточка клиента:
- шкала Новый → Постоянный → VIP;
- прогресс и условия следующего уровня;
- завершённые и учтённые заказы;
- учтённая сумма;
- дата получения текущего статуса;
- ручной выбор статуса;
- возврат к автоматическому расчёту.

База данных:
- Customer.statusOverride;
- Customer.statusOverrideAt;
- миграция 20260606230000_customer_status_rules.

Проверки:
- TypeScript: успешно;
- Next.js: компиляция и проверка типов успешно; локальный процесс остановился на сборе данных страниц из-за отсутствия рабочей БД/лимита времени окружения.
