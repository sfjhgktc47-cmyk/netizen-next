Фикс: расширенный импорт позиций через XLSX.

Что изменено:
1. /nz-console/positions теперь имеет кнопку «Скачать шаблон».
2. /api/admin/positions/template отдаёт готовый XLSX-шаблон.
3. /api/admin/positions/import теперь умеет:
   - обновлять существующие позиции по SKU: price, oldPrice, stock, status и другие переданные поля;
   - создавать новую SKU-позицию из Excel;
   - находить материнскую модель по productId, productSlug/modelSlug или названию model/product;
   - создавать материнскую модель автоматически, если её нет;
   - создавать категорию автоматически, если её нет;
   - не затирать заполненные поля пустыми ячейками.

Минимум для обновления существующей позиции:
sku, price, stock

Минимум для создания новой позиции:
sku, model, brand, category, name, price, stock

Поддерживаются русские и английские названия колонок:
sku / артикул
price / цена
oldPrice / старая цена / цена до акции
stock / остаток / наличие / количество
model / product / модель / товар
brand / бренд
category / категория
name / title / название / позиция
color / цвет
memory / память
sim / сим
images / image / фото / картинки
status / статус
